# AeroWorld

Simulador civil AeroWorld para Windows 10/11 (64 bits).

## Download

[Baixar AeroWorld para Windows](https://github.com/gustavorizzo-cmd/aeroworld-download/releases/latest/download/AeroWorld-Setup.exe)

O instalador inclui o jogo e as dependencias necessarias. Depois da instalacao,
use o atalho **AeroWorld**. O inicializador verifica novas versoes e instala
atualizacoes por cima do aplicativo existente, preservando saves e
configuracoes.

Este repositorio publica somente o instalador compilado. O codigo-fonte do jogo
nao faz parte desta distribuicao publica.
